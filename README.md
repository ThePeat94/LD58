# Bounties and Badasses

This game is my personal entry for the LD58 Game Jam. The entry can be found [here](https://ldjam.com/events/ludum-dare/58/bounties-badasses) and it can be played [here](https://nidavellirgames.itch.io/bounties-badasses).

It is a dating sim roguelite game, where you need to match with other profiles, to collect their bounties, paying your debt at Rednit, a demon contractor.
